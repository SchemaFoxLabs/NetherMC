## プロジェクトと公式規則

NetherMC は、閉鎖されたサーバーを再構築した、営利を目的としないコミュニティプロジェクトです。

**Minecraft の公式サービスではなく、Mojang または Microsoft の承認・提携もありません。** [Minecraft EULA](https://www.minecraft.net/en-us/eula)、[Usage Guidelines](https://www.minecraft.net/en-us/usage-guidelines)、[Community Standards](https://www.minecraft.net/en-us/community-standards) も遵守してください。

この説明は本サーバーと直接関連するコミュニティのみを対象とし、公式契約を置き換えたり、適用法上排除できない権利・義務を排除したりするものではありません。

## 現在の運営と将来の支援

現在、サーバーでは外観、権限、その他の有料コンテンツを販売しておらず、スポンサー支援、寄付、支払いも受け付けていません。将来、正規の Minecraft オンラインアカウントを持つプレイヤーが、実際のサーバーホスティング費用を直接支援できる仕組みを検討する可能性があります。導入する場合は、開始前に別途案内します。

将来の資格は正規の Minecraft オンラインアカウントの UUID／IGN に対応し、現実の身元の公開を求めません。現在その窓口はありません。実施する場合は、その時点の規則と関連ライセンスを踏まえて別途案内します。

Support Rank と通報報酬は購入によらない貢献報酬で、金銭的支援とは無関係です。資格は確認が必要で、提出・受け付けだけでは成立しません。

## プレイヤー間の取引

運営側はプレイヤー間取引の預かり、決済、資金回収サービスを提供しません。適用法上排除できない義務は除外しません。サーバーと公式管理コミュニティ内の禁止された商業取引、法定通貨・仮想通貨取引、FSPoint の通貨利用はサーバー規則で扱います。

## 対応能力と資料の相談

Staff は、対応可能な時間と証拠に応じて確認を進めます。一部の通報は長期間保留となる場合があります。

通常の 1～7 日、繁忙期の 8～30 日は、最初の対応または返信の目安にすぎず、特に機能提案ではこれを超える場合があります。調査完了、問題解決、処分の期限ではありません。

補足資料を提出する前の相談・事前確認専用：`mc-contact@schemafoxlabs.com`。非公開のアカウント情報や機微な証拠を送る前に、適切な提出方法を相談してください。**20 MiB** を超える添付ファイルは受信できない場合があります。大きな資料については、まず文章のみのメールで相談してください。

公開 Issue には個人情報などを伏せた資料のみを提出してください。
