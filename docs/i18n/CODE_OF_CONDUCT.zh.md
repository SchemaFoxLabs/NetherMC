## 禁止行为速查

社区的基本要求是善意参与、尊重其他玩家、保护隐私，并将公共频道用于游戏和社区协作。

禁止：

- 仇恨言论，或针对其他玩家的攻击性、侮辱性发言。
- 持续骚扰、威胁、勒索，或泄露他人隐私信息。
- 冒充 Staff 或其他玩家。
- 诈骗、钓鱼、传播恶意链接、刷屏、广告或未经授权的外部媒体链接。
- 性暗示、色情、R18G、CSAM，或违反内容规则的昵称和皮肤。
- 在公共或全域聊天中进行政治宣传、政治动员、发布宣传材料、反复发送政治口号或持续干扰频道用途的政治争论。
- 组织有害邪教、恐怖主义或法西斯活动，包括有害招募、胁迫或鼓吹暴力。
- 攻击服务器、滥用漏洞、使用违规 Bot、作弊、刷取排位分数或狙击玩家。
- 通过 NetherMC 服务进行违规商业活动或法币／虚拟货币交易。
- 将 FSPoint 用作货币、支付、交换价值或服外交易工具。
- 规避封禁、禁言或其他限制。
- 伪造证据、故意歪曲事件、滥用他人的举报记录，或滥用举报和申诉。

## 限制类型

| 类型 | 作用 |
| :--- | :--- |
| **Join Block** | 阻止进入整个 NetherMC 网络 |
| **Feature Block** | 限制指定功能，如全域聊天或 Ranked |
| **SubServer Block** | 阻止进入指定子服；其他子服不会因此自动受限 |

## 违规与处罚

### 聊天与内容

| 违规 | 处罚 |
| :--- | :--- |
| 攻击性或侮辱性发言 | 全域聊天 Feature Block：首次 **1 分钟**，第二次**无限期** |
| 广告／营销、未经授权的外部媒体链接、性暗示、色情或 R18G | 全域聊天 Feature Block：依次 **1 天**、**7 天**、**无限期** |
| 公共或全域聊天中的政治宣传、政治动员、宣传材料、反复政治口号或持续干扰频道用途的政治争论 | 全域聊天 Feature Block：依次 **1 天**、**7 天**、**无限期** |
| 违反昵称或皮肤内容规则 | Join Block 约 **1 天**；皮肤仅支持游戏内举报 |

### 作弊与竞技公平

| 违规 | 处罚 |
| :--- | :--- |
| 反作弊检测 | 涉事子服固定 **15 天** SubServer Block |
| Staff 确认作弊 | 涉事子服 SubServer Block：**7／30／180／360 天**，此后维持 **360 天** |
| 刷取排位分数 | Ranked Feature Block 至赛季结束或无限期 |
| Unranked 单人狙击 | 涉事子服最低 **1 天** SubServer Block，可提高至长期或永久 |
| Ranked 单人狙击 | 涉事子服最低 **30 天** SubServer Block，可提高至长期或永久 |
| 多人协同狙击 | 每个经核实参与账号实施**永久 Join Block** |

Staff 确认作弊的时长表不包含不超过 20 CPS 的 Autoclicker 和 Sprint。该例外仅适用于人工处罚时长表，不影响反作弊处理或其他规则。

单人狙击还可能导致本赛季剩余时间或无限期的 Ranked Feature Block。Ranked 处罚不改变 FSPoint 的正常赛季刷新。

Staff 根据相关游戏记录核实多人协同狙击，包括匹配频次、时间重合度、重复账号、参与人数、场次和行为记录。社区反馈可提供线索；公开指控、转发数量、投票、单次匹配巧合或单项统计异常不能证明参与。NetherMC 没有玩家自建组织系统，因此公会、组织或固定队伍标签不能证明参与。

### 无限期全域限制

以下违规实施**无限期 Join Block**：

- 仇恨言论。
- 有害邪教、恐怖主义或法西斯活动。
- ServerCrasher 等服务器攻击。
- 机器人排位等违规 Bot 自动化。
- CSAM。
- 违规商业活动或法币／虚拟货币交易。
- 将 FSPoint 用作货币、支付、交换价值或服外交易工具。
- 诈骗、钓鱼或恶意链接。
- 持续骚扰、威胁或勒索。
- 泄露或威胁泄露他人隐私信息。
- 规避封禁或禁言。

## 复核与申诉

Staff 根据适用规则和可用证据确定处罚，并考虑持续时间、规模、重复次数、参与情况与影响。举报者自评置信度、举报数量或奖励资格不决定处罚。

合理批评、善意举报和正常申诉不构成违规。证据不足时可能不处罚或要求补充信息。

处罚申诉通过 [NetherMC-PublicReport](https://github.com/Labs-mcdev/NetherMC-PublicReport/blob/main/docs/i18n/README.zh.md) 提交。无限期限制没有预定结束时间；永久限制不会自动到期，但误判可以申诉。没有新事实或证据的重复申诉可合并或关闭。

## 规则变更

新增或加重的处罚通常适用于之后发生的行为。持续违规或当前安全风险可能需要立即实施保护性限制，并记录原因和提供申诉渠道。
