# ゲームプレイ機能と仕組み

[English](../GAMEPLAY_FEATURES.md) · [中文](GAMEPLAY_FEATURES.zh.md) · **日本語** · [हिन्दी](GAMEPLAY_FEATURES.hi-IN.md)

[NetherMC に戻る](README.ja-JP.md)
NetherMC 固有のゲームプレイ、性能、アクセシビリティ改善を説明します。導入中の機能は、サブサーバーによって利用状況が異なる場合があります。

## 戦闘

- エンダーパール、矢、卵、雪玉などの投射物の当たり判定を小さくし、精度を向上。
- 位置更新を高速化。有効な移動位置の精度を、2 tick ごとの 4/32 ブロックから、毎 tick の 1/32 ブロックへ改善。
- プレイヤーと投射物の相互作用に対する遅延補正。
- ヒットイベントが予期せずキャンセルされる問題の修正。

## セキュリティと性能

- 継続的なセキュリティ更新。
- 保守性を高めるため、既存の「スパゲッティコード」を再構築。
- [BambooSpigot](https://github.com/error-nullindex/BambooSpigot) で開発された変更に基づく TPS 改善。

## アクセシビリティ

アクセシビリティ機能は計画中です。動作が確定した時点でこの文書に追加します。
