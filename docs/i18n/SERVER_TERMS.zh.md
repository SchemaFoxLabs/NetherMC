## 项目与官方规则

NetherMC 是一个已关闭服务器的重构版，为不以盈利为目的的社区项目。

**本项目不是 Minecraft 官方服务，未获 Mojang 或 Microsoft 批准，也不与其关联。** 请同时遵守 [Minecraft EULA](https://www.minecraft.net/en-us/eula)、[Usage Guidelines](https://www.minecraft.net/en-us/usage-guidelines) 与 [Community Standards](https://www.minecraft.net/en-us/community-standards)。

本说明仅涉及本服务器及直接相关社区，不替代官方协议，不排除适用法律规定的不可排除权利或义务。

## 当前运营与未来资助

服务器目前不出售任何外观、权限或其他付费内容，也暂不接受赞助、捐赠或付款。未来可能考虑允许使用正版 Minecraft 在线账户的玩家直接资助实际服务器托管费用。任何此类安排都会在开放前另行公布。

未来资格对应正版 Minecraft 在线账户的 UUID／IGN，不要求公开现实身份。目前没有开放该渠道。实际安排将结合届时规则和相关许可另行公布。

Support Rank 与举报奖励属于非购买型贡献奖励，不与资助金额挂钩。资格需经核实，不因提交或受理自动成立。

## 玩家交易

运营团队不提供玩家交易托管、结算或资金追回服务。本说明不排除不可排除的法定义务。服务器及官方管理社区内的违规商业交易、法币或虚拟货币交易、FSPoint 货币化按服务器规则处理。

## 处理能力与资料咨询

Staff 根据可用时间和证据安排核查，部分举报可能较长时间处于待处理状态。

通常 1–7 天、繁忙时 8–30 天仅为初次处理或回复的参考，可能超出，特别是功能请求；不作为调查结束、解决问题或处罚期限。

仅用于补充资料提交前的咨询、预确认：`mc-contact@schemafoxlabs.com`。涉及私密账户资料或敏感证据，请先咨询适当的提交方式。邮箱可能无法接收超过 **20 MiB** 的大附件；较大材料请先通过文字邮件咨询。

公开 Issue 仅提交脱敏资料。
