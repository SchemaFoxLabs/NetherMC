## 禁止事項の一覧

善意で参加し、他のプレイヤーを尊重し、プライバシーを守り、公開チャンネルをゲームとコミュニティの連携に利用してください。

次の行為は禁止です。

- ヘイトスピーチ、他のプレイヤーへの攻撃的・侮辱的発言。
- 継続的な嫌がらせ、脅迫、恐喝、他人の個人情報の公開。
- Staff または他のプレイヤーへのなりすまし。
- 詐欺、フィッシング、悪意あるリンク、スパム、広告、未許可の外部メディアリンク。
- 性的示唆、ポルノ、R18G、CSAM、内容規則に違反するニックネームやスキン。
- 公開・全域チャットでの政治運動、政治的行動の呼び掛け、プロパガンダ、政治的スローガンの反復、チャンネル用途を妨げる継続的な政治論争。
- 有害なカルト、テロ、ファシズム活動の組織化。有害な勧誘、強制、暴力の扇動を含みます。
- サーバー攻撃、脆弱性の悪用、禁止 Bot、チート、Ranked スコアの不正な引き上げ、スナイピング。
- NetherMC のサービスを利用した禁止商取引、法定通貨または仮想通貨の取引。
- FSPoint を通貨、支払い、交換価値、サーバー外取引の手段として利用する行為。
- BAN、ミュート、その他の制限の回避。
- 証拠の捏造、出来事の故意の歪曲、他人の通報記録の悪用、通報・異議申し立ての乱用。

## 制限の種類

| 種類 | 効果 |
| :--- | :--- |
| **Join Block** | NetherMC ネットワーク全体への接続を禁止 |
| **Feature Block** | 全域チャットや Ranked など、指定機能を制限 |
| **SubServer Block** | 指定サブサーバーへの接続を禁止。他のサブサーバーは自動的には制限されません |

## 違反と処分

### チャットとコンテンツ

| 違反 | 処分 |
| :--- | :--- |
| 攻撃的・侮辱的発言 | 全域チャット Feature Block：初回 **1 分**、2 回目は**無期限** |
| 広告・マーケティング、未許可の外部メディアリンク、性的示唆、ポルノ、R18G | 全域チャット Feature Block：**1 日**、次に **7 日**、その後**無期限** |
| 公開・全域チャットでの政治運動、政治的行動の呼び掛け、プロパガンダ、反復する政治的スローガン、継続的で妨害的な政治論争 | 全域チャット Feature Block：**1 日**、次に **7 日**、その後**無期限** |
| ニックネームまたはスキンの内容違反 | 約 **1 日**の Join Block。スキンはゲーム内でのみ通報できます |

### チートと競技の公正性

| 違反 | 処分 |
| :--- | :--- |
| アンチチート検知 | 対象サブサーバーで固定 **15 日**の SubServer Block |
| Staff が確認したチート | 対象サブサーバーで **7／30／180／360 日**の SubServer Block。その後も **360 日** |
| Ranked スコアの不正な引き上げ | シーズン終了まで、または無期限の Ranked Feature Block |
| Unranked の単独スナイピング | 対象サブサーバーで最低 **1 日**、長期または永久までの SubServer Block |
| Ranked の単独スナイピング | 対象サブサーバーで最低 **30 日**、長期または永久までの SubServer Block |
| 複数人による協調スナイピング | 確認された各参加アカウントに**永久 Join Block** |

Staff が確認したチートの処分表からは、20 CPS 以下の Autoclicker と Sprint を除きます。この例外は手動処分表だけに適用され、アンチチートや他の規則には影響しません。

単独スナイピングには、シーズン終了までまたは無期限の Ranked Feature Block が追加される場合があります。Ranked の処分は通常の FSPoint シーズン更新を変更しません。

協調スナイピングは、マッチング頻度、時間の重なり、反復するアカウント、参加人数、試合、行動記録から確認します。コミュニティの情報は手掛かりになりますが、公の告発、拡散数、投票、1 回の偶然のマッチ、単一の統計異常だけでは参加を認定しません。NetherMC にはプレイヤー作成の組織機能がないため、ギルド、組織、固定チームの名称だけでは参加を認定しません。

### 無期限の全域制限

次の違反には**無期限 Join Block**を適用します。

- ヘイトスピーチ。
- 有害なカルト、テロ、ファシズム活動。
- ServerCrasher などのサーバー攻撃。
- 自動 Ranked プレイなどの禁止 Bot。
- CSAM。
- 禁止商取引、法定通貨または仮想通貨の取引。
- FSPoint を通貨、支払い、交換価値、サーバー外取引の手段として利用する行為。
- 詐欺、フィッシング、悪意あるリンク。
- 継続的な嫌がらせ、脅迫、恐喝。
- 他人の個人情報の公開または公開の脅迫。
- BAN またはミュートの回避。

## 再確認と異議申し立て

Staff は適用規則と利用可能な証拠に基づき、期間、規模、反復、参加、影響を考慮して処分を決定します。通報者の確信度、通報数、報酬資格は処分を決めません。

合理的な批判、善意の通報、通常の異議申し立ては違反ではありません。証拠が不足する場合、処分を行わないか、追加情報を求めることがあります。

異議申し立ては [NetherMC-PublicReport](https://github.com/Labs-mcdev/NetherMC-PublicReport/blob/main/docs/i18n/README.ja-JP.md) から提出してください。無期限の制限には終了予定がありません。永久制限は自動的に終了しませんが、誤認について異議を申し立てられます。新しい事実や証拠のない反復申請は、まとめて処理または終了する場合があります。

## 規則の変更

新設または加重された処分は、原則として以後の行為に適用します。継続中の違反や現在の安全上の危険には、理由を記録し、異議申し立て手段を設けたうえで、直ちに保護的制限を適用する場合があります。
