This page describes NetherMC-specific gameplay, performance, and accessibility work. Availability may differ by subserver while features are being introduced.

## Combat

- Smaller and more precise projectile hitboxes, including ender pearls, arrows, eggs, and snowballs.
- Faster position updates: valid movement position precision improves from 4/32 block every two ticks to 1/32 block every tick.
- Latency compensation for player and projectile interactions.
- Fixes for unexpected cancelled hit events.

## Security and performance

- Ongoing security updates.
- Reconstruction of legacy “noodle code” for clearer maintenance.
- TPS improvements based on changes developed in [BambooSpigot](https://github.com/error-nullindex/BambooSpigot).

## Accessibility

Accessibility features are planned and will be documented here when their behavior is defined.
